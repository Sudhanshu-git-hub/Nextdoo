## Prioritized implementation boundary

Close S1–S5 with focused tests, representative route-level authorization and production browser-header regressions. Keep S6–S8 and unmet chapter-wide requirements visible. No authentication redesign, provider expansion, historical migration edit, image deployment stack, or product feature work. Full local tests/build/lint/types plus hosted audit/migration/restore/real-ClamAV/full-browser checks remain required before delivery.

Audit follow-up S3: the OAuth callback accepts possession of state without checking the currently authenticated browser account. The bounded fix will also bind consumption to that account, so a state issued to one user cannot attach another browser user's Google authorization. The callback will retain its fixed Settings redirect and generic error marker.
