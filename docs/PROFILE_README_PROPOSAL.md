# Sudhanshu Kumar

Personal productivity software engineer and open-source maintainer.

## Building

I build **NEXTDOO** — a personal productivity and life-management workspace
that connects goals, milestones, tasks, trackers, knowledge, calendar, and
progress insights into one workspace. The web application is a Next.js +
PostgreSQL monorepo with a real test suite, security gates, and CI.

- 📦 Repository: [github.com/Sudhanshu-git-hub/Nextdoo](https://github.com/Sudhanshu-git-hub/Nextdoo)

## Tech I work with

- TypeScript, React, Next.js (App Router)
- PostgreSQL, Drizzle ORM, hand-authored SQL migrations
- pnpm workspaces, Turborepo, Vitest, Playwright
- ESLint/typescript-eslint, Node.js 22
- Security: Argon2id, TOTP MFA, secret scanning, ASVS-oriented control reviews

## Open-source activity

- Maintainer of NEXTDOO (design, implementation, review, release management)
- Believer in honest verification: tests must run against real databases and
  real browsers; planned features are never presented as shipped

## Contribution opportunities

NEXTDOO is under active development and welcomes contributions:

- Bug fixes and small features (see `CONTRIBUTING.md`)
- Tests, documentation, and accessibility improvements
- Provider integrations (calendar, storage, notifications) behind the
  documented acceptance gates

Start with the issue tracker and [CONTRIBUTING.md](https://github.com/Sudhanshu-git-hub/Nextdoo/blob/main/CONTRIBUTING.md).
